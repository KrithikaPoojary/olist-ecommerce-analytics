E-commerce Sales & Customer Analytics | MySQL, Python, Power BI
- Analyzed 100K+ Olist orders across 7 tables using SQL joins, CTEs and window functions; built KPI dashboard tracking revenue (R$15.4M), AOV and delivery performance
- Found that late deliveries (~7% of orders) cut avg review score from ~4.3 to ~2.3; identified North/Northeast states (AL, MA, SE) with up to ~21% late rate
- Built RFM segmentation on 93K customers; found "At Risk" high spenders (~15% of customers) hold ~27% of revenue and recommended a win-back campaign
- Cleaned data in pandas (missing dates, duplicate reviews) and published the full project on GitHub
