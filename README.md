How to Run
1. Download the dataset from Kaggle and load it into MySQL with `python/load_data.py` (edit the password and folder path at the top).
2. Run `sql/queries.sql` in MySQL Workbench.
3. Run `python/analysis.py` for the charts and `python/export_powerbi.py` to export the CSVs for Power BI.

Dataset
[Brazilian E-Commerce Public Dataset by Olist (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce). Raw CSVs are not included.
